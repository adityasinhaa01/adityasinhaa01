### About Me

I’m a **Computer Science &amp; Engineering** student focused on writing clean, reliable software — pairing algorithmic fundamentals in **C++ &amp; Java** with practical backend, full-stack, and AI systems.

- **Problem Solving &amp; Core CS:** Practising **Data Structures &amp; Algorithms** in **C++** and **Java**, grounded in OOP, Operating Systems, and DBMS.
- **Backend &amp; Full-Stack:** Designing structured REST APIs and web platforms with **Spring Boot**, **Node.js**, **Express.js**, **FastAPI**, and **React.js**.
- **Applied AI &amp; LLMs:** Exploring **LLM integration**, **Retrieval-Augmented Generation (RAG)**, **Vector Databases**, **Model Context Protocol (MCP)**, tool calling, and semantic search.
